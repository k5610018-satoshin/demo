初期セットアップ

管理者用の設定画面です。API キーとスプレッドシートを設定してください。

1. Speech-to-Text API キー 未設定

Google Cloud の Speech-to-Text API キーを入力してください。

  1. Google Cloud Console で Speech-to-Text API を有効化
  2. 「認証情報」→「認証情報を作成」→「API キー」を作成
  3. 下の入力欄に貼り付けて「保存」

2. スプレッドシート 未作成

既存のスプレッドシート ID を指定するか、空欄のまま「作成」を押すと自動作成します。
